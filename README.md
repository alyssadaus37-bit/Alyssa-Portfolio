# 🌟 Alyssa's Interactive Web Portfolio

A modern, responsive, and interactive web portfolio built with Laravel and React/Inertia.js, featuring a Glassmorphism visual aesthetic to showcase software development projects and UI/UX design work.

---

## 🛠️ Tech Stack & Tools
* **Framework:** Laravel (PHP) + React (Inertia.js)
* **Styling:** CSS3 / Tailwind CSS (Glassmorphism design)
* **Database:** MySQL
* **Tools:** Visual Studio Code, Git, GitHub

---

## 🚀 Local Setup Instructions

### Prerequisites
* PHP >= 8.1
* Composer
* Node.js & npm
* MySQL Database (XAMPP / Local server)
